# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our documentation](https://github.com/changesets/changesets).

We have a quick list of common questions that get asked as you contribute to this repo:

## How do I add a changeset?

Run `npm run changeset` (or `npx changeset add`) after making your changes. It will ask you:

1. Which packages should have a release (here it is always `zademy-tools`)
2. What type of semver bump it should be (`patch`, `minor`, or `major`)
3. A summary of the changes — this goes into the changelog

Commit the generated file in `.changeset/` together with your changes and open a pull request.

## What happens next?

When your PR is merged to `master`, the Release workflow opens (or updates) a version PR that bumps
`package.json`, consumes all pending changesets, and updates `CHANGELOG.md`. Merging that version PR
creates a git tag for the release.

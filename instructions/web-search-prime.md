# Web Search Prime — Public Web Discovery

## Role
Use Web Search Prime to **discover** current public Internet sources when the correct URL is not yet known.

## Routing Priority
- Version-specific library/API documentation covered by Context7 → Context7 first.
- Known URL → Web Reader.
- Public GitHub repository internals → Zread.
- Local repository code → CodeGraph.
- Durable project history → Engram.

Use Web Search Prime for recent releases, current documentation locations, service changes, known errors, news, specifications, and other public information requiring discovery or freshness.

## Workflow
1. Form a concise query using exact names, versions, error strings, and dates when known.
2. Prefer official documentation, official repositories, specifications, maintainers, and primary sources.
3. Refine ambiguous searches instead of guessing.
4. When a conclusion depends on the full page, open the selected URL with Web Reader.
5. Once a relevant public GitHub repository is identified and repository-level inspection is needed, switch to Zread.

Do not present search snippets as full-page evidence. Do not invent URLs, versions, features, or results. Avoid repeated searches that add no new information and never include secrets or confidential code in queries.
